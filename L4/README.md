# Лабораторна робота №4 — Нейронні мережі

- `L4.ipynb` — самодостатній виконаний блокнот: навчання CNN, ONNX/INT8,
  вимірювання швидкодії та маршрутизація.
- PDF — звіт.
- `models/` — навчені ваги PyTorch, FP32/INT8 ONNX, історія та конфігурація навчання.
- `requirements-lab4.txt` — версії пакетів для виконання блокнота.

## Запуск

Перевірено з Python 3.14. Встановіть залежності в окреме середовище:

```shell
python -m venv .venv
# Активуйте середовище відповідно до своєї ОС.
python -m pip install -r requirements-lab4.txt
```

Відкрийте блокнот у Jupyter або VS Code, виберіть це середовище як kernel.
Робоча папка — `L4/`, щоб `models/` була поруч із блокнотом.
MNIST завантажується через інтернет, результати записуються в `results/lab4/`.

`TRAIN_MODEL=False` використовує готові ваги, але повторює оцінку точності,
вимірювання та мережеві досліди. `True` повторює також навчання й експорт.
Код усіх модулів уже включено в блокнот.

CPU підтримується. Для вимірювань CUDA встановіть відповідну GPU-збірку
PyTorch; команда для використаної CUDA 13.0 наведена у requirements.
Нові вимірювання часу можуть відрізнятися від збережених.
