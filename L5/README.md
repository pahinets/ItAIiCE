# Лабораторна робота №5 — Великі мовні моделі

- `L5.ipynb` — самодостатній виконаний блокнот із tools контролера,
  вимірюваннями двох квантувань і 15 запитами для кожного.
- PDF — звіт.
- `assets/` — компактна CNN ONNX INT8, фіксовані зображення й топологія з ЛР4,
  їх походження та SHA256.
- `results/` — сирі вимірювання, протокол, 30 діалогів, демонстрації,
  пояснення моделей і оцінки, прив'язані до hash оригінальних відповідей.
- `requirements-lab5.txt` — залежності блокнота; PyTorch не потрібен.

## Перегляд збереженого досліду

Перевірено з Python 3.14:

```shell
python -m venv .venv
# Активуйте середовище відповідно до своєї ОС.
python -m pip install -r requirements-lab5.txt
```

Відкрийте блокнот у Jupyter або VS Code з цим середовищем як kernel.
Робоча папка — `L5/`, поруч мають бути `assets/` і `results/`.

Збережений блокнот має `RUN_LIVE=False`: це явно позначений replay реального
досліду 18.11.2026, а не нові вимірювання. Для повністю офлайн-перегляду
встановіть також `LIVE_SMOKE=False`. Збережене `LIVE_SMOKE=True` виконує
окремий живий запит до локального Ollama, який не входить у 15 критичних запитів.

## Новий live-дослід

Потрібен Ollama (використано 0.40.16) і дві моделі тієї самої Qwen2.5 3B Instruct.
Приклад для PowerShell:

```powershell
$env:OLLAMA_HOST='127.0.0.1:11435'
$env:OLLAMA_MAX_LOADED_MODELS='1'
$env:OLLAMA_NUM_PARALLEL='1'
ollama serve
```

В іншому вікні з тим самим `OLLAMA_HOST`:

```powershell
$env:OLLAMA_HOST='127.0.0.1:11435'
ollama pull qwen2.5:3b-instruct-q4_K_M
ollama pull qwen2.5:3b-instruct-q8_0
```

Точні digest, обладнання, параметри й лічильники збережені в
`results/performance.json`. Великі ваги LLM не включені до репозиторію.
`RUN_LIVE=True` повторює вимірювання й діалоги та перезаписує результати:
перед запуском збережіть копію папки. Для нових відповідей потрібна нова
змістова перевірка — старі verdict не застосовуються до інших hash.

Змістові оцінки в наявному досліді виконав ШІ-автор реалізації, а не незалежна
людина. Оригінальні невдалі виклики та помилкові твердження моделей збережено.
